# Security reporting

Do not attach personal identity documents, face images, live JWTs or phone links to public issues. Use synthetic reproductions.

Report vulnerabilities through the repository's private security advisory facility when available. Include the affected revision, reproduction steps and expected impact without publishing credentials.

This is research and demonstration software. Authentication and ownership checks do not establish document authenticity or operational KYC compliance. See [architecture limitations](docs/architecture.md) and [model terms](docs/models.md).
